📱 App PWA installabile NOVITÀ

La versione offline ora è una PWA (Progressive Web App) con icona, splash screen e funzionamento offline completo. Si installa sulla home dello smartphone come una vera app, senza passare dal Play Store.

  1. Uploadalo su hosting statico (Cloudflare Pages, Netlify, GitHub Pages) — o usa il link qui sotto
  2. Apri il link dal telefono con Chrome (Android) o Safari (iPhone)
  3. Menu del browser → "Aggiungi alla schermata Home" / "Installa app"
  4. Sulla home appare l'icona rosa "GC Impianti" — tappala e usa come app normale, anche offline!

🤖 Vuoi un vero APK Android?

Usa PWABuilder.com (gratis, di Microsoft) per generare un .apk firmato da caricare sul telefono o pubblicare sul Play Store.

  1. Uploada prima la PWA (zip qui sopra) su hosting statico gratuito (Cloudflare Pages consigliato)
  2. Vai su pwabuilder.com, incolla l'URL della tua PWA pubblicata
  3. Analizza → Package for stores → Android → Generate
  4. Scarica il file .apk (funziona su tutti gli Android moderni)
  5. Passalo al telefono e installa (potresti dover abilitare "origini sconosciute")
🚀 Vai a PWABuilder.com

🌐 Frontend Online (build statica)

Contiene tutti i file HTML+JS+CSS della versione online completa (con Magazzino, Notifiche, Storico, Tag liberi). Uploadalo su hosting statico e collegalo al backend FastAPI. Prima di uploadare, imposta la env var REACT_APP_BACKEND_URL sull'URL del tuo backend.
